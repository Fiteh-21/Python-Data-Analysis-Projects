# Python-Data-Analysis-Projects

This repository contains weekly, hands-on data analysis projects completed as part of the TechSkillUp Programme. The work demonstrates practical application of Python for data analysis, from foundational programming concepts to end-to-end data workflows.

Each project showcases newly acquired skills and explores real-world examples using Python tooling and data analysis techniques.

## What This Repository Includes

- Weekly project notebooks and reports covering data cleaning, analysis, visualization, and interpretation
- Practical demonstrations of Python libraries for working with datasets, building insights, and presenting results
- Sample datasets and analysis output related to finance, sales, customer insights, and business scenarios

## Technologies and Tools Used

- Python 3.x
- pandas for data cleaning, transformation, and analysis
- NumPy for numerical operations and array processing
- Matplotlib and Seaborn for data visualization
- Jupyter Notebook for interactive analysis and reporting
- CSV file handling for working with real-world datasets

## Project Structure

- `Week One/` – introductory Python and basic data handling projects
- `Week Two/` – finance-related data analysis with practical business context
- `Week Three/` – pandas fundamentals and advanced data manipulation
- `Week Four/` – sales analysis and reporting using Python data workflows
- `Week Five/` – interactive data exploration and visualization projects
- `Week Six/` – final analysis report, visualization, and project summary

## Learning Focus

- Data wrangling and preprocessing
- Exploratory data analysis (EDA)
- Visualization and storytelling with data
- Applying Python to real-world data problems
- Developing reproducible workflows in Jupyter Notebook
